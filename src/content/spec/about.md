# 关于 Mofukey

欢迎来到 **Mofukey** —— 一个基于 **Shirone** 主题深度定制的二次开发项目，采用 **Material 3 Expressive（M3E）** 设计体系，融合富有表现力的动漫美学与现代 Web 工程实践。

Mofukey 在 Shirone 的基础上进行了视觉、内容与功能方面的定制，形成了属于 Mofukey 自身的设计语言与生态。

## ✦ 设计理念

Mofukey 延续 Shirone 的设计理念，并在此基础上加入独特的视觉风格与功能：

- **富有表现力的视觉语言**：融合动漫风格与 Material 3 Expressive 的设计理念，打造温暖、轻盈且现代的用户界面。
- **动态色彩系统**：基于 HCT 动态生成配色，根据浅色/深色模式以及用户偏好自动调整视觉色彩，同时保持稳定的布局体验。
- **流畅的页面导航**：继承 Shirone 的应用外壳与流畅页面切换机制，在页面跳转过程中尽可能保持状态与体验的连续性。
- **丰富的内容体验**：支持 Markdown 与 MDX，并提供 KaTeX 数学公式、Mermaid 图表、交互式提示框、代码高亮以及自适应图片画廊等功能。
- **Mofukey 专属扩展**：在 Shirone 基础上加入 Mofukey 自身的页面、内容、功能模块以及视觉定制。
- **按需加载的集成**：评论系统、网站统计、音乐组件等第三方功能可以按需加载，在未启用时尽可能减少额外的 DOM 与资源开销。

## ✦ 技术栈

- **基础主题**：[Shirone](https://github.com/LyraVoid/Shirone)
- **框架**：[Astro 7](https://astro.build/) & [Svelte 5](https://svelte.dev/)
- **样式**：[Tailwind CSS 4](https://tailwindcss.com/) & [Stylus](https://stylus-lang.com/)
- **设计体系**：[Material 3 Expressive](https://m3.material.io/)
- **字体**：Outfit & Yozai（悠哉圆体）
- **搜索引擎**：[Pagefind](https://pagefind.app/) 离线全文搜索
